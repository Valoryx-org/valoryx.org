# Valoryx Cloud

Valoryx Cloud es la forma mas sencilla de crear, organizar y publicar documentacion profesional. Registrese, comience a escribir y comparta — nosotros nos encargamos del resto.

## Que puede hacer

| | |
|---|---|
| **Escriba con claridad** | Un editor WYSIWYG limpio que se siente como Google Docs — pero su contenido se almacena en Markdown, asi que siempre es portable. |
| **Publique al instante** | Un clic para convertir su workspace en un sitio de documentacion con URL personalizada, busqueda y diseno adaptado a moviles. |
| **Colabore con su equipo** | Invite editores, asigne roles, deje comentarios. Vea quien esta editando en tiempo real. |
| **Conecte su GitHub** | Sincronice opcionalmente sus documentos con un repositorio de GitHub. Edite en el navegador o en su IDE — todo se mantiene sincronizado automaticamente. |
| **Conecte herramientas de IA** | El servidor MCP integrado permite que Claude, Cursor y otros asistentes de IA lean y escriban en sus documentos directamente. |

## Primeros pasos

1. **Registrese** en [app.valoryx.dev](https://app.valoryx.dev/#/register) — gratis, sin tarjeta de credito
2. **Cree un workspace** — dele un nombre y estara listo para escribir
3. **Agregue paginas** — haga clic en "+ New Page" en la barra lateral para crear su primer documento
4. **Invite a su equipo** — vaya a Workspace Settings → Members para agregar colaboradores
5. **Publique** — vaya a Workspace Settings → Published Docs para hacer publicos sus documentos

Eso es todo. Sin servidores que administrar, sin software que instalar, sin archivos de configuracion que editar.
