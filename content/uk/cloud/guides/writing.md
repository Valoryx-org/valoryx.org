# Написання та редагування

Valoryx Cloud надає вам чистий редактор без відволікань, який працює як Google Docs — але зберігає все у Markdown для максимальної портативності.

## Створення сторінки

1. Відкрийте робочий простір з панелі керування
2. Натисніть **+ New Page** у бічній панелі
3. Введіть заголовок і починайте писати

Сторінки зберігаються автоматично під час введення тексту. Кожне збереження створює версію в історії робочого простору, тому ви завжди можете повернутися до попереднього стану.

## Редактор

Редактор має два режими:

- **Режим форматованого тексту** (за замовчуванням) — форматуйте текст за допомогою панелі інструментів або клавіатурних скорочень. Що бачите — те й отримуєте.
- **Режим Markdown** — перемкніться на чистий Markdown для точного контролю. Натисніть кнопку `</>` на панелі інструментів.

### Клавіатурні скорочення

| Дія | Windows/Linux | Mac |
|---|---|---|
| Жирний | Ctrl+B | ⌘+B |
| Курсив | Ctrl+I | ⌘+I |
| Заголовок | Ctrl+1/2/3 | ⌘+1/2/3 |
| Посилання | Ctrl+K | ⌘+K |
| Блок коду | Ctrl+Shift+C | ⌘+Shift+C |
| Зберегти | Ctrl+S | ⌘+S |

### Що можна додати

- **Форматування тексту** — жирний, курсив, закреслений, виділення
- **Заголовки** — від H1 до H6
- **Списки** — маркіровані, нумеровані, контрольні списки
- **Блоки коду** — з підсвіткою синтаксису для 100+ мов
- **Таблиці** — зміна розміру стовпців, додавання/видалення рядків
- **Зображення** — перетягування або вставка з буфера обміну
- **Посилання** — на інші сторінки робочого простору або зовнішні URL-адреси
- **Виноски** — блоки інформації, попередження, поради та небезпеки
- **Роздільники** — горизонтальні лінії для розділення секцій

## Організація сторінок

Сторінки розташовані плоским списком у бічній панелі. Ви можете:

- **Перетягувати** для зміни порядку сторінок
- **Перейменовувати** подвійним кліком на назві сторінки у бічній панелі
- **Видаляти** через меню ⋯ сторінки

## Шляхи сторінок

Кожна сторінка має шлях (наприклад, `getting-started` або `api/authentication`). Шляхи зі слешами створюють візуальне групування у бічній панелі та в навігації опублікованої документації.

## AI-асистент написання

Натисніть кнопку ✨ на панелі інструментів, щоб скористатися AI-інструментами для написання:

- **Покращити** — вдосконалити граматику, ясність і тон
- **Скоротити** — зробити текст більш лаконічним
- **Розширити** — додати деталі та пояснення
- **Переписати** — переформулювати в іншому стилі
- **Чат** — задавайте питання про вашу документацію та отримуйте контекстні відповіді

AI-функції використовують Claude або OpenAI (налаштовується адміністратором робочого простору).
