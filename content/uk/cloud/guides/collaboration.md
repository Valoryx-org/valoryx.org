# Командна робота

Valoryx Cloud створений для команд. Запрошуйте колег, контролюйте, хто може редагувати, та бачте зміни в реальному часі.

## Запрошення учасників

1. Перейдіть у **Workspace Settings** → **Members**
2. Введіть електронну адресу колеги
3. Оберіть роль (див. нижче)
4. Натисніть **Send Invitation**

Колега отримає лист із посиланням для приєднання. Якщо в нього ще немає облікового запису Valoryx, йому буде запропоновано створити його.

## Ролі

| Роль | Що може робити |
|---|---|
| **Viewer** | Переглядати всі сторінки. Не може редагувати чи змінювати налаштування. |
| **Commenter** | Переглядати всі сторінки та залишати коментарі. Не може редагувати контент. |
| **Editor** | Створювати, редагувати та видаляти сторінки. Не може змінювати налаштування робочого простору. |
| **Admin** | Все, що може Editor, плюс керування учасниками та налаштуваннями. |
| **Super Admin** | Повний контроль, включаючи оплату, Git sync та критичні дії. |

## Присутність у реальному часі

Коли кілька людей перебувають в одному робочому просторі, ви бачитимете їхні аватари у верхній панелі. Якщо хтось редагує ту саму сторінку, що й ви, ви побачите позицію його курсора з підсвіткою.

## Стрічка активності

Кожен робочий простір має стрічку активності з останніми змінами:

- Хто редагував яку сторінку і коли
- Запрошення учасників та зміни ролей
- Події Git sync
- Зміни публікації

Знайти її можна на панелі керування робочого простору.

## Коментарі

Залишайте коментарі на будь-якій сторінці для обговорення змін із командою. Коментарі з'являються у бічній панелі поряд із контентом. Позначайте їх як вирішені, коли обговорення завершено.
