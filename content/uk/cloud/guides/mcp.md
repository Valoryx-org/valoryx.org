# AI та інтеграція з MCP

Valoryx Cloud має вбудований MCP-сервер (Model Context Protocol), який дозволяє AI-асистентам взаємодіяти з вашою документацією напряму.

## Що таке MCP?

MCP — це стандартний протокол, який дозволяє AI-інструментам підключатися до зовнішніх сервісів. Уявіть, що це спосіб дати Claude або Cursor можливість "бачити" вашу документацію та вносити зміни — з вашого дозволу.

## Що AI може робити з вашою документацією

- **Читати** сторінки, щоб відповідати на питання про вашу документацію
- **Шукати** по всіх сторінках, щоб знаходити потрібний контент
- **Створювати** нові сторінки за вашими інструкціями
- **Редагувати** наявні сторінки (переписувати, покращувати, перекладати)
- **Аналізувати** документацію на предмет прогалин, неточностей або застарілого контенту

## Налаштування

### У Claude Desktop

1. Перейдіть у **Workspace Settings** → **API Keys**
2. Створіть API-ключ (Read & Write або Read Only)
3. У налаштуваннях Claude Desktop додайте цей MCP-сервер:

```json
{
  "mcpServers": {
    "valoryx-docs": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-remote", "https://app.valoryx.dev/api/v1/mcp"],
      "env": {
        "API_KEY": "your-api-key-here"
      }
    }
  }
}
```

4. Перезапустіть Claude Desktop
5. Запитайте Claude: *"Що є в моїй документації?"*

### У Cursor

Та сама конфігурація — додайте MCP-сервер у налаштуваннях Cursor і використовуйте той самий API-ключ.

## Доступні MCP-інструменти

MCP-сервер надає 13 інструментів:

| Інструмент | Що робить |
|---|---|
| `list_pages` | Перелік усіх сторінок у робочому просторі |
| `read_page` | Читання вмісту конкретної сторінки |
| `create_page` | Створення нової сторінки |
| `update_page` | Оновлення наявної сторінки |
| `delete_page` | Видалення сторінки |
| `search` | Повнотекстовий пошук по всіх сторінках |
| `list_workspaces` | Перелік доступних робочих просторів |
| *...та інші* | Коментарі, метадані, структура дерева |

## Безпека

- API-ключі хешуються (ніколи не зберігаються у відкритому вигляді)
- Ви контролюєте рівень доступу: Read Only або Read & Write
- Відкликайте ключі будь-коли з Workspace Settings
- Усі MCP-запити фіксуються в журналі аудиту
