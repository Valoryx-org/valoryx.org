# Valoryx Cloud

Valoryx Cloud — це найпростіший спосіб створювати, організовувати та публікувати професійну документацію. Зареєструйтесь, почніть писати та поділіться — ми подбаємо про все інше.

## Що ви можете робити

| | |
|---|---|
| **Зручне написання** | Чистий WYSIWYG-редактор, який працює як Google Docs — але ваш контент зберігається у Markdown, тому він завжди портативний. |
| **Миттєва публікація** | Один клік — і ваш робочий простір перетворюється на живий сайт документації з власною URL-адресою, пошуком та адаптивним дизайном. |
| **Командна робота** | Запрошуйте редакторів, призначайте ролі, залишайте коментарі. Бачте, хто редагує, в реальному часі. |
| **Підключення GitHub** | За бажанням синхронізуйте документацію з репозиторієм GitHub. Редагуйте у браузері або в IDE — все синхронізується автоматично. |
| **Підключення AI-інструментів** | Вбудований MCP-сервер дозволяє Claude, Cursor та іншим AI-асистентам читати та редагувати вашу документацію напряму. |

## Початок роботи

1. **Зареєструйтесь** на [app.valoryx.dev](https://app.valoryx.dev/#/register) — безкоштовно, без кредитної картки
2. **Створіть робочий простір** — дайте йому назву і починайте писати
3. **Додайте сторінки** — натисніть "+ New Page" у бічній панелі, щоб створити перший документ
4. **Запросіть команду** — перейдіть у Workspace Settings → Members, щоб додати співавторів
5. **Опублікуйте** — перейдіть у Workspace Settings → Published Docs, щоб зробити документацію публічною

Ось і все. Жодних серверів для обслуговування, жодного софту для встановлення, жодних конфігураційних файлів для редагування.
