# Valoryx Cloud

Valoryx Cloud ist der einfachste Weg, professionelle Dokumentation zu erstellen, zu organisieren und zu veröffentlichen. Registrieren Sie sich, beginnen Sie zu schreiben und teilen Sie Ihre Inhalte — wir kümmern uns um den Rest.

## Was Sie tun können

| | |
|---|---|
| **Ansprechend schreiben** | Ein übersichtlicher WYSIWYG-Editor, der sich wie Google Docs anfühlt — aber Ihre Inhalte bleiben in Markdown, damit sie jederzeit portabel sind. |
| **Sofort veröffentlichen** | Ein Klick verwandelt Ihren Workspace in eine Live-Dokumentationsseite mit eigener URL, Suchfunktion und mobilfreundlichem Layout. |
| **Im Team zusammenarbeiten** | Laden Sie Redakteure ein, weisen Sie Rollen zu, hinterlassen Sie Kommentare. Sehen Sie in Echtzeit, wer gerade bearbeitet. |
| **GitHub verbinden** | Synchronisieren Sie Ihre Dokumentation optional mit einem GitHub-Repository. Bearbeiten Sie im Browser oder in Ihrer IDE — alles bleibt automatisch synchron. |
| **KI-Tools verbinden** | Der integrierte MCP-Server ermöglicht Claude, Cursor und anderen KI-Assistenten, Ihre Dokumentation direkt zu lesen und zu bearbeiten. |

## Erste Schritte

1. **Registrieren** Sie sich unter [app.valoryx.dev](https://app.valoryx.dev/#/register) — kostenlos, keine Kreditkarte erforderlich
2. **Workspace erstellen** — geben Sie ihm einen Namen und schon können Sie loslegen
3. **Seiten hinzufügen** — klicken Sie auf „+ New Page" in der Seitenleiste, um Ihr erstes Dokument zu erstellen
4. **Team einladen** — gehen Sie zu Workspace Settings → Members, um Mitarbeiter hinzuzufügen
5. **Veröffentlichen** — gehen Sie zu Workspace Settings → Published Docs, um Ihre Dokumentation öffentlich zu machen

Das war's. Keine Server zu verwalten, keine Software zu installieren, keine Konfigurationsdateien zu bearbeiten.
