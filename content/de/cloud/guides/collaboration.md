# Zusammenarbeit im Team

Valoryx Cloud ist für Teams gebaut. Laden Sie Ihre Kollegen ein, kontrollieren Sie, wer was bearbeiten darf, und sehen Sie Änderungen in Echtzeit.

## Teammitglieder einladen

1. Gehen Sie zu **Workspace Settings** → **Members**
2. Geben Sie die E-Mail-Adresse ein
3. Wählen Sie eine Rolle (siehe unten)
4. Klicken Sie auf **Send Invitation**

Die eingeladene Person erhält eine E-Mail mit einem Link zum Beitritt. Falls sie noch kein Valoryx-Konto hat, wird sie zur Registrierung aufgefordert.

## Rollen

| Rolle | Berechtigungen |
|---|---|
| **Viewer** | Alle Seiten lesen. Kein Bearbeiten oder Ändern von Einstellungen. |
| **Commenter** | Alle Seiten lesen und Kommentare hinterlassen. Kein Bearbeiten von Inhalten. |
| **Editor** | Seiten erstellen, bearbeiten und löschen. Keine Workspace-Einstellungen ändern. |
| **Admin** | Alles, was ein Editor kann, plus Mitglieder und Einstellungen verwalten. |
| **Super Admin** | Volle Kontrolle einschließlich Abrechnung, Git Sync und kritischer Aktionen. |

## Echtzeit-Präsenz

Wenn mehrere Personen im selben Workspace arbeiten, sehen Sie deren Avatare in der oberen Leiste. Bearbeitet jemand dieselbe Seite wie Sie, wird dessen Cursorposition hervorgehoben.

## Aktivitäts-Feed

Jeder Workspace verfügt über einen Aktivitäts-Feed, der aktuelle Änderungen anzeigt:

- Wer welche Seite wann bearbeitet hat
- Einladungen und Rollenänderungen
- Git-Sync-Ereignisse
- Veröffentlichungsänderungen

Sie finden ihn im Workspace-Dashboard.

## Kommentare

Hinterlassen Sie Kommentare auf jeder Seite, um Änderungen mit Ihrem Team zu besprechen. Kommentare erscheinen in einer Seitenleiste neben dem Inhalt. Markieren Sie sie als erledigt, wenn die Diskussion abgeschlossen ist.
