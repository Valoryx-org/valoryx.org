# Dokumentation veröffentlichen

Verwandeln Sie jeden Workspace in eine ansprechende, öffentliche Dokumentationsseite. Ihre Leser erhalten ein schnelles, durchsuchbares und mobilfreundliches Erlebnis — Sie bekommen eine Live-Seite, die sich bei jedem Speichern automatisch aktualisiert.

## So veröffentlichen Sie

1. Gehen Sie zu **Workspace Settings** → **Published Docs**
2. Aktivieren Sie **Enable publishing**
3. Ihre Dokumentation ist sofort unter `app.valoryx.dev/p/your-workspace-slug/` erreichbar

Das war's. Jede Seite in Ihrem Workspace ist nun öffentlich zugänglich.

## Was Ihre Leser sehen

Die veröffentlichte Dokumentation umfasst:

- **Navigations-Seitenleiste** — wird automatisch aus Ihrer Seitenstruktur generiert
- **Volltextsuche** — Leser finden jede Seite oder jeden Abschnitt sofort
- **Mobilfreundliches Layout** — funktioniert auf Smartphones, Tablets und Desktops
- **Syntaxhervorgehobener Code** — alle Code-Blöcke werden farblich korrekt dargestellt
- **Inhaltsverzeichnis** — wird automatisch aus den Überschriften jeder Seite generiert
- **Dark Mode** — Leser können zwischen hellem und dunklem Design wechseln

## Eigene Domains

Mit den Tarifen **Team** und **Business** können Sie Ihre eigene Domain verwenden:

1. Gehen Sie zu **Workspace Settings** → **Custom Domain**
2. Geben Sie Ihre Domain ein (z. B. `docs.ihreFirma.com`)
3. Fügen Sie den angezeigten DNS-Eintrag hinzu (ein CNAME, der auf unsere Server verweist)
4. Das SSL-Zertifikat wird automatisch bereitgestellt — keine Einrichtung nötig

## Themes

Wählen Sie aus 7 integrierten Themes, die zu Ihrer Marke passen. Jedes Theme bietet anpassbare Farben für Header, Seitenleiste und Akzente.

## Veröffentlichung aufheben

Deaktivieren Sie die Veröffentlichung jederzeit. Ihre Dokumentation wird sofort wieder privat. Der Inhalt bleibt in Ihrem Workspace — nichts wird gelöscht.
