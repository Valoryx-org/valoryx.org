# Valoryx Cloud

Valoryx Cloud est le moyen le plus simple de creer, organiser et publier une documentation professionnelle. Inscrivez-vous, commencez a ecrire et partagez — nous nous occupons du reste.

## Ce que vous pouvez faire

| | |
|---|---|
| **Ecrivez avec elegance** | Un editeur WYSIWYG epure qui fonctionne comme Google Docs — mais votre contenu reste en Markdown, toujours portable. |
| **Publiez instantanement** | Un clic suffit pour transformer votre espace de travail en un site de documentation en ligne avec une URL personnalisee, un moteur de recherche et une mise en page adaptee aux mobiles. |
| **Collaborez avec votre equipe** | Invitez des editeurs, attribuez des roles, laissez des commentaires. Voyez qui edite en temps reel. |
| **Connectez votre GitHub** | Synchronisez vos documents avec un depot GitHub si vous le souhaitez. Editez dans le navigateur ou votre IDE — tout reste synchronise automatiquement. |
| **Connectez des outils IA** | Le serveur MCP integre permet a Claude, Cursor et d'autres assistants IA de lire et modifier vos documents directement. |

## Pour commencer

1. **Inscrivez-vous** sur [app.valoryx.dev](https://app.valoryx.dev/#/register) — gratuit, sans carte bancaire
2. **Creez un espace de travail** — donnez-lui un nom et vous etes pret a ecrire
3. **Ajoutez des pages** — cliquez sur "+ New Page" dans la barre laterale pour creer votre premier document
4. **Invitez votre equipe** — allez dans Workspace Settings → Members pour ajouter des collaborateurs
5. **Publiez** — allez dans Workspace Settings → Published Docs pour rendre vos documents publics

C'est tout. Aucun serveur a gerer, aucun logiciel a installer, aucun fichier de configuration a modifier.
