# Collaboration en equipe

Valoryx Cloud est concu pour le travail en equipe. Invitez vos collegues, controlez qui peut modifier quoi et suivez les changements en temps reel.

## Inviter des collaborateurs

1. Allez dans **Workspace Settings** → **Members**
2. Saisissez leur adresse e-mail
3. Choisissez un role (voir ci-dessous)
4. Cliquez sur **Send Invitation**

Ils recevront un e-mail contenant un lien pour rejoindre l'espace. S'ils n'ont pas encore de compte Valoryx, ils seront invites a en creer un.

## Roles

| Role | Permissions |
|---|---|
| **Viewer** | Lecture de toutes les pages. Ne peut ni modifier ni changer les parametres. |
| **Commenter** | Lecture de toutes les pages et ajout de commentaires. Ne peut pas modifier le contenu. |
| **Editor** | Creation, modification et suppression de pages. Ne peut pas modifier les parametres de l'espace. |
| **Admin** | Tout ce qu'un Editor peut faire, plus la gestion des membres et des parametres. |
| **Super Admin** | Controle total, y compris la facturation, le Git sync et les actions sensibles. |

## Presence en temps reel

Lorsque plusieurs personnes se trouvent dans le meme espace de travail, vous voyez leurs avatars dans la barre superieure. Si quelqu'un modifie la meme page que vous, la position de son curseur est mise en evidence.

## Fil d'activite

Chaque espace de travail dispose d'un fil d'activite montrant les changements recents :

- Qui a modifie quelle page et quand
- Les invitations de membres et changements de roles
- Les evenements de Git sync
- Les modifications de publication

Retrouvez-le dans le tableau de bord de l'espace de travail.

## Commentaires

Laissez des commentaires sur n'importe quelle page pour discuter des modifications avec votre equipe. Les commentaires apparaissent dans un panneau lateral a cote du contenu. Marquez-les comme resolus lorsque c'est fait.
