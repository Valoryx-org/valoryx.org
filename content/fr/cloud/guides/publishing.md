# Publier votre documentation

Transformez n'importe quel espace de travail en un site de documentation public et soigne. Vos lecteurs beneficient d'une experience rapide, avec recherche integree et adaptee aux mobiles — et vous obtenez un site qui se met a jour a chaque sauvegarde.

## Comment publier

1. Allez dans **Workspace Settings** → **Published Docs**
2. Activez **Enable publishing**
3. Vos documents sont immediatement en ligne a l'adresse `app.valoryx.dev/p/your-workspace-slug/`

C'est tout. Chaque page de votre espace de travail est desormais accessible publiquement.

## Ce que vos lecteurs voient

La documentation publiee inclut :

- **Barre de navigation laterale** — generee automatiquement a partir de la structure de vos pages
- **Recherche plein texte** — vos lecteurs peuvent trouver n'importe quelle page ou section instantanement
- **Mise en page adaptee aux mobiles** — fonctionne sur telephones, tablettes et ordinateurs
- **Code avec coloration syntaxique** — tous les blocs de code s'affichent avec les couleurs appropriees
- **Table des matieres** — generee automatiquement a partir des titres de chaque page
- **Mode sombre** — vos lecteurs peuvent basculer entre le theme clair et le theme sombre

## Domaines personnalises

Avec les offres **Team** et **Business**, vous pouvez utiliser votre propre domaine :

1. Allez dans **Workspace Settings** → **Custom Domain**
2. Saisissez votre domaine (par exemple `docs.votreentreprise.com`)
3. Ajoutez l'enregistrement DNS affiche (un CNAME pointant vers nos serveurs)
4. Le certificat SSL est provisionne automatiquement — aucune configuration necessaire

## Themes

Choisissez parmi 7 themes integres pour correspondre a votre identite visuelle. Chaque theme propose des couleurs personnalisables pour l'en-tete, la barre laterale et les accents.

## Depublier

Desactivez la publication a tout moment. Vos documents redeviennent immediatement prives. Le contenu reste dans votre espace de travail — rien n'est supprime.
