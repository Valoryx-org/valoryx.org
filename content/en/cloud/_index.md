Valoryx Cloud is the easiest way to create, organize, and publish professional documentation. Sign up, start writing, and share — we handle everything else.

## What you can do

| | |
|---|---|
| **Write beautifully** | A clean WYSIWYG editor that feels like Google Docs — but your content stays in Markdown, so it's always portable. |
| **Publish instantly** | One click to turn your workspace into a live documentation site with a custom URL, search, and mobile-friendly layout. |
| **Collaborate with your team** | Invite editors, assign roles, leave comments. See who's editing in real time. |
| **Connect your GitHub** | Optionally sync your docs with a GitHub repo. Edit in the browser or your IDE — everything stays in sync automatically. |
| **Connect AI tools** | Built-in MCP server lets Claude, Cursor, and other AI assistants read and write your docs directly. |

## Getting started

1. **Sign up** at [app.valoryx.dev](https://app.valoryx.dev/#/register) — free, no credit card required
2. **Create a workspace** — give it a name and you're ready to write
3. **Add pages** — click "+ New Page" in the sidebar to create your first document
4. **Invite your team** — go to Workspace Settings → Members to add collaborators
5. **Publish** — go to Workspace Settings → Published Docs to make your docs public

That's it. No servers to manage, no software to install, no configuration files to edit.
