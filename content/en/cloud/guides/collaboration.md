# Team Collaboration

Valoryx Cloud is built for teams. Invite your colleagues, control who can edit what, and see changes in real time.

## Inviting teammates

1. Go to **Workspace Settings** → **Members**
2. Enter their email address
3. Choose a role (see below)
4. Click **Send Invitation**

They'll receive an email with a link to join. If they don't have a Valoryx account, they'll be prompted to create one.

## Roles

| Role | What they can do |
|---|---|
| **Viewer** | Read all pages. Cannot edit or change settings. |
| **Commenter** | Read all pages and leave comments. Cannot edit content. |
| **Editor** | Create, edit, and delete pages. Cannot change workspace settings. |
| **Admin** | Everything an Editor can do, plus manage members and settings. |
| **Super Admin** | Full control including billing, git sync, and danger zone actions. |

## Real-time presence

When multiple people are in the same workspace, you'll see their avatars in the top bar. If someone is editing the same page as you, you'll see their cursor position highlighted.

## Activity feed

Every workspace has an activity feed showing recent changes:

- Who edited which page and when
- Member invitations and role changes
- Git sync events
- Publishing changes

Find it in the workspace dashboard.

## Comments

Leave comments on any page to discuss changes with your team. Comments appear in a sidebar next to the content. Mark them as resolved when done.
