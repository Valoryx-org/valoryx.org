Эта запись объединяет всё, что вышло между v0.6.4 и v0.11.1. Полная детализация по каждому релизу входит в changelog документации продукта.

## MCP-сервер: 26 инструментов

Встроенный MCP-сервер вырос с 13 до **26 инструментов** — CRUD контента, поиск, RAG-пакеты контекста, проверка качества, версионирование, экспорт, AI-помощь при написании, комментарии, активность, публикация рабочих пространств и разрешение конфликтов git-синхронизации. Два транспорта: stdio для локальных AI-инструментов, Streamable HTTP для облачного доступа. [См. страницу MCP](/mcp/).

## Публикация как код

- **Оверлей публикации** — `.docplatform/publish.yaml` даёт проверяемый через git контроль над тем, какие именно страницы становятся публичными; он переопределяет frontmatter для каждого пути.
- **Манифест навигации** — `.docplatform/nav.yaml` описывает публикуемую боковую панель как версионируемый файл.
- **7 тем**, теперь валидируемых из единого источника истины.
- **Честное поведение бейджа** — платные тарифы действительно скрывают футер «Powered by Valoryx»; Community/Free показывает его с понятным путём апгрейда.

## Редактор и рабочее пространство

- Перемещение страниц перетаскиванием в дереве рабочего пространства
- Переключатель «сырого» Markdown и автосохранение с обнаружением конфликтов (409 + трёхстороннее представление)
- Переименование рабочего пространства, более понятные названия ролей, письма-приглашения с указанием роли
- Список ожидающих приглашений и индикаторы опубликованных страниц

## Git-синхронизация

- **Учётные данные шифруются при хранении** (AES-256-GCM)
- Подключение пустого репозитория автоматически инициализирует его (init-and-push)
- Авто-коммиты несут реальную личность автора — `git blame` показывает, кто что написал

## Приватность и управление аккаунтом (GDPR)

- Экспорт личных данных и данных вашей организации в режиме самообслуживания
- Удаление аккаунта с подтверждением паролем
- Анонимная opt-in телеметрия по умолчанию остаётся **выключенной**

## Усиление безопасности (основное)

- Закрыт тайминг-оракул при входе; исправлен stored-XSS в пути рендеринга markdown
- SSRF-защита исходящих запросов с закреплением IP и отклонением редиректов
- Исправлен обход авторизации по API-ключам; валидация полезной нагрузки scope
- Блокировка аккаунта распространена на все пути с паролем; AI-действия пропускаются только по белому списку на границе
- Защита от бомб загрузки и zip-бомб
- Закрыта гонка идемпотентности в биллинговом вебхуке

## Облачная редакция

- Чип тарифа, отображение использования и сценарий апгрейда в облачном UI
- Единые ошибки `PLAN_LIMIT_REACHED` во всех путях создания
- 14-дневный пробный период с 7-дневным льготным периодом
