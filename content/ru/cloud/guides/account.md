# Ваш аккаунт

## Регистрация

Перейдите на [app.valoryx.dev](https://app.valoryx.dev/#/register) и создайте аккаунт, указав email и пароль. Вам потребуется принять [Условия использования](/terms/) и [Политику конфиденциальности](/privacy/).

Вы также можете войти через **Google** или **GitHub**, если эти варианты доступны.

## Настройки профиля

Нажмите на аватар в левом верхнем углу, затем **Profile**, чтобы:

- Изменить отображаемое имя
- Обновить email
- Сменить пароль
- Настроить passkey (WebAuthn) для входа без пароля

## Биллинг

Перейдите в **Workspace Settings** → **Billing**, чтобы:

- Просмотреть текущий тариф и использование
- Перейти на тариф Team ($29/мес.) или Business ($79/мес.)
- Управлять подпиской через портал Stripe
- Просматривать счета и историю платежей

## Ваши данные

### Что мы храним

- Ваш email, имя и пароль (хешированный с помощью Argon2id)
- Содержимое вашей документации (в рабочих пространствах)
- Журналы активности (кто что редактировал и когда)

### Что мы не храним

- Номера кредитных карт (обрабатываются полностью через Stripe)
- Ваши Git-учётные данные (OAuth-токены не хранятся долгосрочно)
- Отслеживающие cookies (аналитика только по вашему согласию, в соответствии с GDPR)

### Экспорт данных

Ваш контент всегда остаётся переносимым:

- **С GitHub sync** — ваша документация уже находится в репозитории GitHub в виде Markdown-файлов
- **Без GitHub sync** — используйте кнопку **Export** в настройках рабочего пространства, чтобы скачать ZIP-архив со всеми Markdown-файлами
- **Данные аккаунта** — запросите полный экспорт данных, связавшись с нами

### Удаление аккаунта

Свяжитесь с нами по адресу valoryxeu@gmail.com для запроса удаления аккаунта. Мы удалим все ваши данные в течение 30 дней в соответствии с требованиями GDPR.

## Безопасность

- Пароли хешируются с помощью Argon2id (рекомендовано OWASP)
- Сессии используют HttpOnly cookies (недоступны для JavaScript)
- Весь трафик шифруется с помощью TLS
- Опциональный вход через passkey/WebAuthn без пароля
- Полный журнал аудита всех действий с аккаунтом
