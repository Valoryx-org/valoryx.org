# Написание и редактирование

Valoryx Cloud предоставляет чистый редактор без отвлекающих элементов, который работает как Google Docs, но хранит всё в Markdown для максимальной переносимости.

## Создание страницы

1. Откройте рабочее пространство из панели управления
2. Нажмите **+ New Page** в боковой панели
3. Введите заголовок и начните писать

Страницы сохраняются автоматически по мере ввода. Каждое сохранение создаёт версию в истории вашего рабочего пространства, поэтому вы всегда можете вернуться к предыдущей.

## Редактор

Редактор имеет два режима:

- **Визуальный режим** (по умолчанию) — форматируйте текст с помощью панели инструментов или горячих клавиш. Результат виден сразу.
- **Режим Markdown** — переключитесь на исходный Markdown для точного контроля. Нажмите кнопку `</>` на панели инструментов.

### Горячие клавиши

| Действие | Windows/Linux | Mac |
|---|---|---|
| Bold | Ctrl+B | ⌘+B |
| Italic | Ctrl+I | ⌘+I |
| Heading | Ctrl+1/2/3 | ⌘+1/2/3 |
| Link | Ctrl+K | ⌘+K |
| Code block | Ctrl+Shift+C | ⌘+Shift+C |
| Save | Ctrl+S | ⌘+S |

### Что можно добавить

- **Форматирование текста** — жирный, курсив, зачёркнутый, выделение
- **Заголовки** — от H1 до H6
- **Списки** — маркированные, нумерованные, чек-листы
- **Блоки кода** — с подсветкой синтаксиса для 100+ языков
- **Таблицы** — изменение ширины столбцов, добавление/удаление строк
- **Изображения** — перетаскивание или вставка из буфера обмена
- **Ссылки** — на другие страницы рабочего пространства или внешние URL
- **Выноски** — блоки информации, предупреждения, подсказки и ошибки
- **Разделители** — горизонтальные линии для отделения секций

## Организация страниц

Страницы отображаются плоским списком в боковой панели. Вы можете:

- **Перетаскивать** для изменения порядка
- **Переименовывать** двойным кликом по названию страницы в боковой панели
- **Удалять** через меню ⋯ на странице

## Пути страниц

Каждая страница имеет путь (например, `getting-started` или `api/authentication`). Пути с косой чертой создают визуальную группировку в боковой панели и в навигации опубликованной документации.

## AI-помощник при написании

Нажмите кнопку ✨ на панели инструментов, чтобы использовать AI-инструменты для работы с текстом:

- **Improve** — улучшение грамматики, ясности и тона
- **Shorten** — сокращение текста
- **Expand** — добавление деталей и пояснений
- **Rewrite** — перефразирование в другом стиле
- **Chat** — задавайте вопросы о вашей документации и получайте контекстные ответы

AI-функции используют Claude или OpenAI (настраивается администратором рабочего пространства).
