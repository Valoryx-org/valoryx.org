# AI и MCP-интеграция

Valoryx Cloud включает встроенный MCP-сервер (Model Context Protocol), который позволяет AI-ассистентам напрямую взаимодействовать с вашей документацией.

## Что такое MCP?

MCP — это стандартный протокол, позволяющий AI-инструментам подключаться к внешним сервисам. Представьте, что это способ дать Claude или Cursor возможность «видеть» вашу документацию и вносить изменения — с вашего разрешения.

## Что AI может делать с вашей документацией

- **Читать** страницы, чтобы отвечать на вопросы о вашей документации
- **Искать** по всем страницам для нахождения релевантного контента
- **Создавать** новые страницы по вашим инструкциям
- **Редактировать** существующие страницы (переписывать, улучшать, переводить)
- **Анализировать** документацию на предмет пробелов, несоответствий или устаревшего контента

## Настройка

> **Статус:** размещённый MCP-эндпоинт для Valoryx Cloud **ещё не включён** — удалённые AI-инструменты пока не могут подключаться к `app.valoryx.dev`. Эта страница будет обновлена, как только он заработает. На **self-hosted** инстансе MCP работает уже сегодня — выполните шаги ниже на машине, где запущен DocPlatform.

### Self-hosted: Claude Desktop

1. Перейдите в **Workspace Settings** → **API Keys**
2. Создайте API-ключ — он начинается с `dp_live_` и показывается только один раз
3. В `claude_desktop_config.json` добавьте:

```json
{
  "mcpServers": {
    "docplatform": {
      "command": "docplatform",
      "args": ["mcp", "--workspace", "my-docs", "--api-key", "dp_live_abc123"]
    }
  }
}
```

4. Перезапустите Claude Desktop
5. Спросите Claude: *«Что содержится в моей документации?»*

### В Cursor

Та же конфигурация — добавьте ту же запись `docplatform` в `.cursor/mcp.json` вашего проекта.

## Доступные MCP-инструменты

MCP-сервер предоставляет 26 инструментов:

| Инструмент | Что делает |
|---|---|
| `list_pages` | Список всех страниц в рабочем пространстве |
| `read_page` | Чтение содержимого конкретной страницы |
| `write_page` | Создание страницы или её обновление, если она уже существует |
| `update_page` | Обновление существующей страницы |
| `delete_page` | Удаление страницы |
| `search` | Полнотекстовый поиск по всем страницам |
| `list_workspaces` | Список доступных рабочих пространств |
| *...и другие* | Комментарии, метаданные, древовидная структура |

## Безопасность

- API-ключи хешируются (никогда не хранятся в открытом виде)
- Вы контролируете область доступа каждого ключа: `read`, `write` и `delete`
- Отзывайте ключи в любой момент через Workspace Settings
- Сбои авторизации записываются в журнал, а каждое изменение контента отслеживается в истории страницы
