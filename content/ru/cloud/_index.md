# Valoryx Cloud

Valoryx Cloud — самый простой способ создавать, организовывать и публиковать профессиональную документацию. Зарегистрируйтесь, начните писать и делитесь — мы позаботимся обо всём остальном.

## Что вы можете делать

| | |
|---|---|
| **Удобное написание** | Чистый WYSIWYG-редактор, который работает как Google Docs, но ваш контент хранится в Markdown, поэтому он всегда остаётся переносимым. |
| **Мгновенная публикация** | Один клик — и ваше рабочее пространство превращается в полноценный сайт документации с пользовательским URL, поиском и адаптивной вёрсткой. |
| **Командная работа** | Приглашайте редакторов, назначайте роли, оставляйте комментарии. Видьте, кто редактирует в реальном времени. |
| **Подключение к GitHub** | При желании синхронизируйте документацию с репозиторием GitHub. Редактируйте в браузере или в IDE — всё синхронизируется автоматически. |
| **Подключение AI-инструментов** | Встроенный MCP-сервер позволяет Claude, Cursor и другим AI-ассистентам напрямую читать и редактировать вашу документацию. |

## Начало работы

1. **Зарегистрируйтесь** на [app.valoryx.dev](https://app.valoryx.dev/#/register) — бесплатно, без привязки карты
2. **Создайте рабочее пространство** — придумайте название, и можно начинать писать
3. **Добавьте страницы** — нажмите "+ New Page" в боковой панели, чтобы создать первый документ
4. **Пригласите команду** — перейдите в Workspace Settings → Members, чтобы добавить участников
5. **Опубликуйте** — перейдите в Workspace Settings → Published Docs, чтобы сделать документацию публичной

Вот и всё. Никаких серверов для управления, никакого ПО для установки, никаких конфигурационных файлов для редактирования.
